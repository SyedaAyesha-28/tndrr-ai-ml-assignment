# Tndrr AI/ML Assignment

This repository contains the work for three AI/ML assignment tasks.

## Tasks

### Task 1: LoRA

The `task1_lora/` folder contains the training and evaluation scripts, data files, results, logs, screenshots, and LoRA adapter output.

### Task 2: RAG

The `task2_rag/` folder contains the retrieval-augmented generation scripts, question files, evaluation results, logs, screenshots, and the source PDF.

### Task 3: Local LLM

The `task3_local_llm/` folder contains scripts and result files for benchmarking and evaluating a local language model.

## Repository contents

- `task1_lora/` — Task 1 files
- `task2_rag/` — Task 2 files
- `task3_local_llm/` — Task 3 files
- `Report Tasks Description.pdf` — Assignment description, if included

## Notes

Python virtual environments and cache folders are excluded from version control. To run the scripts, create and activate a Python virtual environment, then install the dependencies required by the task.
